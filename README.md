# Joel Victor Portfolio

My Web Development Assignment 2 portfolio for Ontario Tech University. It was built with Node.js, Express, and EJS.

## Pages

- **Home** — A short introduction and links to my work.
- **About Me** — My education, skills, work experience, and goals.
- **Projects** — My coursework in networking, cybersecurity, Python, and web development.
- **Contact Me** — A contact form and links to GitHub and LinkedIn.

## Run locally

From the project folder, run:

```sh
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
